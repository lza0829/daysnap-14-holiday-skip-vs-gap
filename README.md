# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

本地拆跑：

```bash
# API
cd backend && pip install -r requirements.txt
$env:夹具目录='..\fixtures'; uvicorn app.main:app --port 11600

# 前端
cd frontend && npm install && npm run dev
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺上一营业日有效镜、偏离阈值（假期不计断档） |
| 营业日历 | 假期登记；非营业日只落非有效占位 |
| 旁置簿 | 未入账载荷 |

## 假期跳日（已落地）

口径：**假日占位非有效镜**。

- 非营业日抽取只写 `状态='假期占位'` 的非有效行（余额空、仅「开端来源日=上一营业日」继承标记）；
  当日无流水则假期无任何行。二态在核证接口逐项可区分：`有行 / 占位有无 / valid`。
- 下一营业日有效镜开端直接取「上一营业日**有效**镜」，不取日历前一日；假期流水按窗口
  `(上一营业日, 营业日]` 归到下一营业日，抽取与回放共用。
- 断档只针对营业日；假期永不记待补断档。
- 改日历与抽取/断档扫描经 `BEGIN IMMEDIATE` + 数据库触发器失败闭：任何路径都写不出假期有效镜，
  有有效镜的日子不能改成假期，有占位的日子不能直接恢复营业。

接口：`GET /api/日历`、`POST /api/日历/改日`、`POST /api/日历/批量`、`GET /api/日历变更`、
`GET /api/核证?营业日=&账户键=`。

夹具：`假期中日夹具.json`（三日中中日假期）、`假期迟到夹具.json`（假期迟到装载）、
`改日历并发夹具.json`（改日历与抽取交错）。测试：`backend/tests/test_假期跳日.py`。
